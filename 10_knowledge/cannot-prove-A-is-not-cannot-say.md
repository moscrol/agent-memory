# 「不能证明 A」不等于「不能说」

> **性质：`hypothesis`。** 从一次真实分析归纳，n=1。

## 判据

为了防自欺，你会给自己的读数加限定——"**这些数据不能用于支撑 X**"。**这个限定对内是必要的**，它是诚实的基础设施。

但它有一个副作用：**限定容易被当成"对外也不能提"**。于是同一份数据，因为不能证明 A，被整体封存——**哪怕它能干净地证明 B，而 B 恰好是对方真正在判断的东西。**

**关键动作不是放松纪律，是先问一句：这份数据到底能证明什么命题？**

同一份数据常常「不能证明 A / 恰好能证明 B」。把 A 的限定套到 B 上，等于自己把最强的牌扣住。

## 典型场景：早期投资

| | |
|---|---|
| 命题 A | **产品有效、用户用得起来** |
| 0 用户阶段 | **没有任何人能证明 A** —— 它不是"你还没证明"，是这个阶段不存在该证据 |
| 所以对方实际在判断 | 命题 B：**这个创始人的结论可不可信** —— 他真懂吗？自己用吗？被现实改过吗？诚实吗？ |
| 创始人自用记录 | **不能证明 A**（样本是一个有强动机的人）· **恰好能证明 B**（且难以伪造） |

**"我的方法没通过检验"并被原样记录**，是 B 类证据里最强的一种——因为它逆着自身利益，而且可验证。

## 怎么用（三步）

1. 把加了限定的读数列出来
2. 逐条问：**它不能证明 A，那它能干净地证明什么？**
3. 能证明 B 的，**另做一份只讲 B 的材料**——不是放松原限定，是**换一个命题重新组织**

原来的内部限定**一个字都不改**。两份材料讲的是两件事。

## 适用条件

- 有严格内部证据纪律的项目（这条判据只对"已经做对了第一步"的人有用）
- 面对的对方**无法验证 A**，只能判断 B（早期投资、招聘、合作、找第一批用户）

## 失效条件

- **数据本身有问题**（样本污染、口径不清、无法复核）→ 那是数据问题，不是命题问题，**别用本条去救**
- **对方要的就是 A**，B 对他没有意义（例：采购方要的是效果证明，不是你可不可信）
- **把 B 讲得像 A**（"我自己用了 495 次" → 暗示"所以产品有效"）→ 这是偷换命题，**比不讲更糟**，而且一旦被识破会同时毁掉 B
- 内部限定本身是错的（读数其实能支撑 A）→ 先改限定，不是另做材料

## 与项目的关系（推测）

对 [[foresight]]：`validation.md` B 段的限定"不能用于支撑产品有效或用户用得起来"**完全正确，不该改**。但 B 段内容（20 天 495 次提问 / 124 条纠偏 / 83 个可证伪点）+ C 段的"三条种子规则全部未获支持并原样记录"，**是命题 B 的强证据**。

**不能据本条改 `validation.md` 的任何限定。** 本条只主张：另做一份讲命题 B 的材料，且必须写明它不证明 A。
