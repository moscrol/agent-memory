# 判断沉淀六条规则

## 结论 / 要点

记忆库的价值不在条目数，在**每条能不能被复用**。下面六条是可操作判据，写一条记忆前逐条过。

### 1. 不记「是什么」，记「这意味着什么」

```
✗ 裸事实:     "中际旭创 Q1 毛利率 46.06%"
✗ 带判断事实: "毛利率 46.06% 创新高"
✓ 可复用判断: "毛利率 46.06% 创新高，证明 1.6T 放量初期定价权仍强，
              打破价格战担忧。核心跟踪变量：Q2 是否维持 >47%"
```

判据：这个数据改变了哪个判断？什么都没改变就别记——**裸数据回 provider 查，记忆不是缓存**。

### 2. 写框架，不写答案

推荐会随价格过时，排序逻辑可跨标的复用。

```
✗ "生益科技值得买"
✗ "光模块产业链：上游 InP → 中游 EML → 下游光模块"（清单型）
✓ "AI 硬件链价值分配不取决于需求增速，取决于供给弹性。
   按弹性排序：CCL M9（0 弹性）> ABF 载板 > 光模块（量驱动非价驱动）> 液冷（无约束）"
```

### 3. 每条框架必须写「什么时候失效」

写完追问一句：什么信号出现时这条不再成立？答案写成最后一段。

```
✓ "该框架前提是「利率重定价为冲击主因、基本面健康」。
   若基本面恶化，轮动节奏崩塌；若冲击是叙事裂痕型而非利率型，跳过第一阶段直入第二阶段。"
```

### 4. 写「触发条件 + 信号组合」，不写单点预测

信号分三级：**领先**（预判）/ **确认**（执行）/ **滞后**（验证）。

```
✗ "中际旭创目标价 1500" / "Q3 光模块会涨"
✓ "加仓触发：毛利率 >45% + 经营性现金流/净利修复至 40%+ + 公募持仓 <20%，三条同时满足才执行。
   减仓触发：毛利率跌破 46% 或公募持仓 >20%。"
```

### 5. 框架错了就升级，不静默覆盖 ⭐

被市场推翻时**不要删 v1 写 v2**，保留修正链：

```
v1: "最脆弱标定法：板块最脆弱标的放量跌破关键支撑 → V 回确认出清"
  ↓ 市场表现推翻
v2: "需区分两种出清模式——(A) 恐慌放量+V回型（1-3 天）
    (B) 买盘枯竭缩量一字型（周期更长）。当前处于 (B)，不应按 (A) 的时间预期等底部"
```

三个好处：①知道 v1 在什么条件下失败过 ②下次先判断属于 A 还是 B ③避免反复横跳——v2 再被推翻时有完整进化树。

**这条是六条里最该先落地的**：现在的沉淀是覆盖式的，错了改掉就没了，等于每次都从零开始。

### 6. 抽象要能脱离原对话独立理解

实操标准：**三个月后重读，不需要回忆当时对话背景**，就能理解这条在说什么、为什么成立、什么时候失效。

```
✗ "这个逻辑成立"（哪个逻辑？）
✗ "北向连续流出+缩量，短期情绪偏弱"（三天后失效，时点绑定）
✓ "行业盈利预期持续上修、估值未明显压缩时，主升期回调优先检查催化兑现节奏；
   盈利预期转弱则该模式失效"
```

## 转化模板

```
标题: [一句话概括判断，≤20 字]

模式/框架:
- 因果关系：因为 X → 所以 Y
- 适用范围：什么条件下有效
- 信号组合：领先（预判）/ 确认（执行）/ 失效（推翻）

关键依据:
- 数据支撑（来源 + 时间）
- 逻辑链（中间假设与变量）

失效边界:
- 什么信号出现时该判断不再成立
```
