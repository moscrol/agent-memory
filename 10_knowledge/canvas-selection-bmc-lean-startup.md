# 商业模式画布不止一张

> 来源：Paweł Huryn（Product Compass）转述，pm-skills 仓。**未验证，按对该来源的信任采纳。**
> 注意分层：**三张画布本身是行业标准框架**（Osterwalder / Maurya / Huryn）；**"什么时候该用哪张"的取舍判断是作者观点**（`author-view`）。

## 判据

画布选错，会系统性地漏掉某一类问题——而且你不会察觉，因为每一格都填满了。

| 画布 | 作者 | 特点 | 已知缺什么 |
|---|---|---|---|
| **Business Model Canvas** | Osterwalder | 九格全景，最通用 | 无愿景 · 无"抄不走"测试 · 无取舍（不做什么）· 无关键指标 · 早期产品的 Key Partners / Key Resources 两格填不出有用的东西 |
| **Lean Canvas** | Ash Maurya | 用 Problem / Solution / Unfair Advantage 换掉 Partners / Activities / Resources | 更适合假设检验，但仍把**战略**和**商业模式**混在一起 |
| **Startup Canvas** | Paweł Huryn | 把战略（9 节）与商业模式（成本结构 + 收入来源）**分开** | 作者本人的框架，采用度远低于前两者 |

**BMC 那五个缺口里，最容易伤人的是"无取舍"**——画布只让你写做什么，不逼你写不做什么。而早期产品的聚焦几乎全部来自"不做什么"。

## 适用条件（原文语境）

- **BMC**：成熟业务、公司战略、**投资人材料**——需要讲清各运营环节怎么串起来时
- **Lean Canvas**：快速假设检验
- **Startup Canvas**：新产品，需要战略清晰度与商业模式同时在场时

## 什么时候我不用它

- **我要回答的是"这件事该不该做"时。** 三张画布都只描述"怎么做"。痛点没验证之前画任何画布，都只是在给假设排版。
- **一个人、没有合作伙伴和雇员时**：BMC 左半边（Key Partners / Key Activities / Key Resources）产出基本为零，填了也是凑数。
- 已经有真实收入与客户结构时——此时该看的是实际单位经济，不是画布。

## 与项目的关系（推测）

对 [[foresight]]：BP 是给创业营的**投资人材料**（BMC 的典型适用场景），但产品处在 **0 用户 0 收入**阶段（Lean / Startup Canvas 的场景）。两个用途拉扯同一张画布时，不要指望一张能同时服务——这和 [[solo-breakeven-needs-founder-hours-column]] 里"一人事业与融资路线不该共用一张评分表"是同一个形状。
