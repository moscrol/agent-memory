# 独立收敛是比单方主张更强的证据

> **性质：`hypothesis`（跨案例归纳）。** n=2，且"独立性"本身尚未核实（见失效条件第一条）。

## 判据

当两个互不相关的团队、在不同领域、**独立演化出同一组约束**时，这组约束大概率是**领域无关**的。

这比任何一方的论证都强——因为没有互相抄袭的可能，也没有共享的理论前提在托底。**收敛本身就是证据**，而且是免费的。

## 实例：AI 教学蓝本 vs 金融投研 agent（2026-09-13）

`xx-hub/craft-your-textbook`（破卷生态，做 AI 苏格拉底教学蓝本）与本人的 agent 工程体系（金融投研），在下面五条上说的是同一件事：

| 约束 | 破卷的表述 | 我们的表述 |
|---|---|---|
| **生成方不能审自己** | 蓝军审校：写作 agent 以"生成流畅内容"为目标，审计 agent 以"证伪具体主张"为目标，**永远不让写作 agent 审计自己** | `agent-run-review` 独立复核；finance 仓组件打分器的独立盲评 |
| **审计者要上下文干净** | 审计 agent 从零读产出文件 + 权威源，**不看建造日志** | 独立盲评五维 rubric，判官不参与生成 |
| **断言要能回源** | 打赌测试：写具名引用/数字前问"我愿意打赌这是真的吗"，有一丝犹豫就降级为间接转述 | stance 标注、`[实测]/[推断]/[假设]`、断言纪律 |
| **审计结论不能照单全收** | "核实后才改"：修法依据是**权威源**不是审计员建议；误判保留不动并注明否决原因 | 断言纪律的证据等级 |
| **不要单 agent 脑内左右互搏** | 老师与学生共享上下文时，学生的"误区"是老师脑补的，**没有独立性价值** | eval-harness 方差纪律、A/B 差分要求真实分叉 |

## 怎么用

遇到一条 agent 工程约束，问一句：**有没有另一个领域独立得出过同样的结论？**

- 有 → 可以当**通用约束**用，移植到新领域时不必重新论证
- 没有 → 它可能只是本领域的经验，移植前要先验证

## 适用条件

- 两个来源确实互不相关（没有共同上游、没有互相引用）
- **表述形式不同但机制相同**——表述如果一模一样反而可疑

## 失效条件

- **⚠ 两方其实有共同上游**（都读过同一本书、同一篇论文、同一个开源项目、同一家厂商的工程博客）→ 那不是独立收敛，是**同源传播**，证据力归零。
  **这条必须先查**，而且是本判据最容易出错的地方——当下 agent 工程圈共享话语极多，"同时出现"远不等于"独立得出"。
  上面那个实例**尚未核实独立性**，所以它现在只是提示。
- 收敛的是**流行做法**而非**被真实约束逼出来的做法**——流行会让很多人同时做同一件事，与正确无关
- **n=2 就下结论**。两个实例是提示，不是定论
