# 路演材料先定主线再改页面

> **性质：`hypothesis`（n=1 归纳）。** 一次实测得出的工作法，未在第二个项目上复现。

## 判据

口播稿、幻灯片、阅读版 BP 是同一个故事的三种投影。只要它们由不同会话、不同工具、不同日期生成，就会各自迭代、各自变好、然后分叉。

**改任何一份之前，先做「主词交叉计数」**：把 A 的主词（标题、反复出现的那个概念）在 B 里数一遍，再把 B 的主词在 A 里数一遍。

- 两个方向都为零 = 已经分叉。此时逐页润色是白费，先定基准。
- 基准的挑法：最新的一份，且与产品事实源（product / decisions）一致的那份。其余两份向它对齐。

为什么是"计数"而不是"读一遍看看像不像"：读的时候人会自动脑补衔接，两份都写得不错就会觉得"差不多"；计数不会。零就是零。

## 适用条件

- 有两份以上对外讲述材料，且不是从同一个源文件一次生成的（单源多投影时交叉计数恒非零，本判据无用）。
- 有一份产品事实源可以当裁判，否则"谁是基准"只能凭喜好。

## 失效条件

- 主办方给了固定模板、要求逐页对应 BP 章节 → 基准是模板不是最新稿，本判据的"挑最新那份"失效。
- 三份材料本来就由同一条管线从同一源生成 → 分叉不会发生，不需要数。
- 交叉计数不为零但主线仍不同（同一个词在两份里意思不一样）→ 计数这个探针漏报，要退回逐段对读。

## 与项目的关系（推测）

[[foresight]] 2026-09-15 实测：口播稿主词「认知投降」在 pptx v2（15 页正文 + 备注）出现 0 次；pptx 主词「让每一次判断，都有下文」「三个断点」在口播稿出现 0 次；仓内另有第三份 Marp deck。处置：以口播稿为基准（最新、过了三岗、与 product.md 核心痛点一致），pptx 与 BP 向它对齐。

可迁移到：短视频的脚本 / 封面文案 / 简介三件；BP 正文与申请表答案；任何"一份材料被多个 agent 分头改过"的场合。
