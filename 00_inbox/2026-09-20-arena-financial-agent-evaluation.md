# Arena 比拼机制与投研 Agent 策略评分讨论

> 原始调查与方案讨论，待提炼。历史官方机制不代表所有现行 Arena 赛道；以下建议不是已经验证的行业标准。

## 已核实的一手来源

- VERIFIED，读取日期 2026-09-20。2023-05-03 的官方介绍将 Chatbot Arena 定义为匿名、随机配对的众包比较；用户同时与两个匿名模型对话，投票后揭示模型名，分析使用身份未揭示时的投票。早期用 Elo 评分，根据对手强弱及胜负估计相对能力。[官方介绍](https://lmsys.org/blog/2023-05-03-arena/)
- VERIFIED，读取日期 2026-09-20。2023-12-07 官方说明从逐场更新的 Elo 转向 Bradley-Terry 模型，对历史配对结果集中估计固定版本的相对评分，提供 bootstrap 置信区间；该版将平局计为半胜半负。其假设要求关注模型版本稳定性，不能把不同版本直接视为同一固定选手。[官方更新](https://lmsys.org/blog/2023-12-07-leaderboard/)
- [推断] 上述机制直接测量所采集问题与用户群体下的相对偏好，不直接证明金融事实正确、任务完成或投资收益；金融应用需额外核验。[依据](https://lmsys.org/blog/2023-05-03-arena/)
- UNVERIFIED，访问日期 2026-09-20。Alpha Arena 官方站点及尝试的博客路径返回 HTTP 429；文本代理也仅返回 Vercel Security Checkpoint。本轮未核实具体资金、资产、时间、参赛模型或排名，不引用这些细节。[官网](https://nof1.ai/)

## 用户补充与纠偏

- 用户明确：投研 Agent 可为持牌机构或内部团队提供策略，选股策略应是正式评分维度，而非只评报告或将策略置于非核心附加项。授权与具体合规边界另行确定。来源：本轮用户对话；通过 canonical record-correction 入口记录，ID `7fe048decc27`。

## 方案建议，非来源事实

- [推断/建议] 分研究盲评、选股与组合策略实绩、运行可靠性三个榜。偏好评分可借用匿名配对；策略表现以事前固定规则的前向记录和独立计算为主，不能由投票代替。
- [推断/建议] 选股排序和组合管理分赛道，避免把杠杆、仓位与市场暴露误当选股能力。选股可看排序与后续收益的关联、分层组合净超额收益；组合再看风险、成本、换手、容量与约束遵守。
- [推断/建议] 事前固定股票池、信息截止时间、资金、成交规则、调仓频率、费用、比较基准及策略更新权限。A 股至少显式处理 T+1、涨跌停、停牌和不可成交情形。完整记录所有预注册策略与失败，避免事后选最优。
- [推断/建议] 历史回放控制资料披露时间、成分股历史版本、退市样本及修订数据，但无法仅靠资料截断排除模型记住后续结果。真正前向测试必须独立成账，短期领先不能证明持续优势。
- [推断/建议] 专业研究员盲评适合开放研究结论；事实和可计算指标需要独立核验。榜单披露版本、样本量和不确定区间，自家产品不由自己单独裁决。

## 提炼提示

- 相对偏好、可验证任务完成和经济表现是不同测量对象。
- 按目标用户与授权用途定义评测范围，不能把公众服务限制直接套到全部内部工具。
