## B. 合约兼营条款核对清单（对照原文打勾）

拿到合约后逐条标：`有 / 无 / 模糊 / 未写`。模糊与未写一律列入「提问清单 C」。

- [ ] 是否允许经营或参与**其他金融相关业务**（含投研工具、内容、咨询、OPC）
- [ ] 是否限制**持牌/非持牌**对外表达（荐股、投顾、保险交叉销售边界）
- [ ] **竞业 / 排他 / 全职投入**条款（是否要求主要时间给友邦）
- [ ] **兼职 / 副业**申报或书面批准流程
- [ ] **客户与线索归属**（友邦客户能否接触 Foresight；反向亦然）
- [ ] **品牌与渠道**使用限制（个人号、公号、矩阵账号是否可推其他产品）
- [ ] **报酬与分成**是否绑定最低产能（产能压力是否挤占产品工时）
- [ ] **保密与数据**是否覆盖个人产品代码、用户数据、训练语料
- [ ] 违约后果与**解除兼营**路径是否写清
- [ ] 有无「事先书面同意」类豁免口子；找谁批、多久批

## C. 合规边界提问清单（问对接人 / 合规，不替你作答）

1. 以个人名义运营 Foresight（投研 Agent / 内容）是否视为「兼营其他金融业务」？  
2. 若 Foresight 暂无收费、仅 Alpha，是否仍需报备？收费后是否升级审批？  
3. OPC 注册与开票，是否与合伙人合约冲突？  
4. 历史「课程 + 持牌投顾」资产与当前产品红线（不荐股等）如何对外切割，公司有无口径要求？  
5. 个人内容矩阵五平台，发非保险内容是否需备案或禁导流到友邦以外产品？  
6. 需要哪些书面批准才能并行？批准失败时的退出方案是什么？
