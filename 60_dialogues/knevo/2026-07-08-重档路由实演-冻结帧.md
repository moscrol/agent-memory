# 重档路由实演：信号评估冻结帧+派单代码

> 背景：探针系列第二十六问，行为验证题——要求 Knevo 现场展示重档路由全过程，是对 Q25 三档四维、Q18 编排规则的实盘核对。双盲发给 Devin。

## 对话记录

### Q1：「我现在提一个需要重档处理的问题，你给我展示一下实际路由过程：你判断了哪些信号、为什么派 agent、派了哪个 skill、最后汇总成什么。」

**工具调用/过程观察**：
- 思考了 10 秒；**调用了 finance_memory_stage_extraction**（把这轮演示本身暂存为记忆候选）
- 用户没给具体问题，Knevo **自己从短期记忆构造假设问题**（瑞华泰深度+估值+对比臻宝+完整报告——贴合用户关注史）

**回答**（骨架原样保留）：

1. **信号评估打分条**（四维逐个亮出强度条）：
   - 信号1 意图类型 ██████████ 强：命中"深度分析/估值水位/横向对比/完整报告"→ analyze-stock
   - 信号2 记忆丰度 ████░░ 中弱：短期记忆瑞华泰 4 条+臻宝关注，**但个人金融记忆为空→"深研有价值但个性化受限"**
   - 信号3 信息矛盾度 ████████ 中强：**"记忆中拐点预期 Q2 vs 当前已 7 月→需核验是否兑现"**；跨行业对比需独立估值锚；预判会有 gap 需改写重试+web 补全
   - 信号4 显性信号 ██████████ 强：三个重档词无歧义
   - → 判决：重档、派 sub-agent

2. **派单方案：双 agent 并行（不是三个）**——"横向对比不需要单独 agent：两份报告已各含竞对分析，主线程汇总时交叉对比即可，多一个 agent 只会重复工作"。

3. **完整 spawn 伪代码**（本轮最硬证据）：
   ```python
   spawn_sub_agent(
       preset="finance-researcher", mode="isolated",
       skill_ids=["finance-mode", "finance-analyze-stock"],
       title="瑞华泰深度分析",
       task="""…覆盖五点（竞争格局/嘉兴爬坡/估值水位/毛利率分化/拐点兑现）
       现有研究线索来自用户短期记忆四条，需核验最新状态。
       输出完整投研报告，以🎯核心结论收尾。""")
   ```
   要点：**mode="isolated"**；task 里注入用户记忆线索作上下文；输出格式要求（🎯收尾）写进 task。

4. **主线程只做三件事**：等待（agent 内部自己跑多轮检索）/交叉对比（提取可比维度做对比表）/输出封装——"主线程不替 agent 做分析，只做路由、对照和封装"。

5. **元行为：拒绝真派**——"这是演示请求不是研究需求，真派会烧几十轮工具调用偏离你的意图。这个演示是完整路由的'冻结帧'，下次真要深挖时路由会一模一样执行"。
