# 技能包全景与选取路由：finance-mode 入口 + 8 专项技能

> 背景：探针系列第十五问，直接问技能包清单与选取方式——本轮把 Knevo 的 skill 全景挖出。双盲发给 Devin（Devin 按自己金融仓的技能包答，作为对照）。

## 对话记录

### Q1：「我看到你挂载了很多技能包？分别管什么场景？我该怎么选取使用」

**工具调用/过程观察**：
- 思考了 1 秒；**调用 `search_skills` 工具，返回空**——随后自述"从今天对话中实际加载过的 workflow 和 skill 完整还原"（工具失败→记忆降级，与 Q2 探针的降级梯度行为一致）

**回答**（骨架原样保留）：

1. **架构：1 入口 + 8 专项 + 底层能力**：
   - **入口层 `finance-mode`**（任何金融关键词自动激活，不需选）：负责检索硬触发规则、数据源路由、记忆/图谱使用纪律、输出格式、一票否决清单——"你在金融模式下说的每一句话，它都在底层兜底"。
   - **执行层 8 专项技能**：
     | 类 | 技能 | 场景 |
     |---|---|---|
     | 公司 | finance-analyze-stock | 个股深度：首次覆盖/估值/竞格/全面画像 |
     | 公司 | finance-earnings-review | 财报复盘：单期数字 vs 预期的窄切面 |
     | 行业 | finance-industry-report | 行业深度：一次性全景地图（画森林） |
     | 行业 | finance-industry-track | 行业跟踪：持续更新的气象预报 |
     | 事件 | finance-forecast-event | 事件推演：概率/情景树/兑现路径——核心不是"会不会"而是"沿 A/B/C 哪条路径传导+各路径概率区间" |
     | 审查 | finance-kol-analyze | KOL 观点画像：质量/历史准确率/偏见 |
     | 审查 | finance-associate | 横向联想：可比/历史类比/遗漏变量/反向思考 |
     | 审查 | finance-review-check | 事实审查：数字核对/估值假设检验/报告复核 |
   - **底层能力层（非技能，每次都在用）**：finance_memory_query / finance_graph_context / finance_entity_resolve / finance_quote / finance_statement / finance_news / finance_search_data。

2. **选取三方法**：
   - 方法一 问题类型法（意图→技能映射表）
   - 方法二 复杂度法：**用户不需要记技能名——finance-mode 内置路由表按意图词自动匹配**
   - 方法三 **语气和粒度就是路由信号**："简单说下浪潮"→主线程快答不派 sub-agent；"全面分析浪潮"→spawn analyze-stock；"Q2 财报怎么看"→spawn earnings-review。

3. **当天实际路由复盘表**：锐捷/垦丰→analyze-stock 自动路由；超节点判据/五维框架/错因归因/全部规则探针→主线程快答（纯方法论不派单）；瑞华泰→主线程快答（已有 15 条记忆，增量更新）。

4. **一句话**："你只需要说想做什么，我自动匹配；想要特定深度或速度，直接说'深度分析'或'快答'。路由细节不需要你操心。"
